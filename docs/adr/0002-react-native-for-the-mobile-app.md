# 0002: React Native with TypeScript for the mobile app

**Status:** Accepted
**Date:** 2026-11-11

The IAS security spec and the first Milestone 1 submission name Flutter; the project charter and the revised milestone name React Native with TypeScript. We build the mobile app in React Native with TypeScript. The charter is the later document, and the API and the benchmarked algorithm code are already TypeScript, so one language covers the app, the API and the shared logic for a five-person team.

## Consequences

- The IAS spec's Flutter references are out of date and should not be used to "correct" the code.
- The first release target is an Android APK (charter M5).
